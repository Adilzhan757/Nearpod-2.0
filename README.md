# Nearpod Interactive (Интербелсенді оқыту платформасы)

Nearpod (https://nearpod.com/) платформасына толыққанды балама ретінде жасалған заманауи білім беру веб-қосымшасы. Мұғалімдерге нақты уақыттағы кері байланыс пен сабақ басқару құралдарын, ал оқушыларға қызықты интерактивті тапсырмаларды ұсынады.

---

## 🌟 Басты мүмкіндіктері (Key Features)

1. **Код арқылы жылдам кіру (Join with 5-Character Code)**:
   - Оқушылар тіркелусіз тек 5 әріптен тұратын кодты (мысалы: `BIO26`, `MARS9`, `SILK7`) енгізіп сабаққа бірден қосылады.
2. **Time to Climb (Шыңға өрмелеу викторинасы)**:
   - Кері санақ таймері, тау биіктігінің анимациясы, стрик көбейткіші және нақты уақыттағы көшбасшылар тақтасы.
3. **Draw It (Интерактивті сурет салу тақтасы)**:
   - Қаламдар, маркер, өшіргіш, түстер палитрасы және биологиялық/математикалық диаграммаларға белгі қойып, мұғалімге тапсыру.
4. **360° VR Field Trip (Виртуалды саяхат)**:
   - Марс ғаламшарына, Олимп жанартауы мен ғарыш кеңістігіне 360 градустық панорамалық интерактивті саяхат (gyro/drag support).
5. **Collaborate Board (Ой бөлісу тақтасы)**:
   - Түрлі-түсті стикерлер жабыстыру және жүрекше қойып ең үздік идеяларға дауыс беру.
6. **Мұғалім консолі (Teacher Live Control)**:
   - Слайдтарды басқару, оқушылардың суреттері мен жауаптарын бақылау, смарта-тақтаға шығарғанда есімдерді жасыру режимі (*Hide Student Names*).
7. **Сабақ құрастыру студиясы & AI (Lesson Studio)**:
   - Жаңа интерактивті сабақтар құру және тақырып бойынша автоматты түрде сабақ жасайтын Nearpod AI көмекшісі.
8. **Есептер мен сараптама (Reports & Analytics)**:
   - Сабақтан кейінгі толық нәтижелер және CSV форматында есепті жүктеп алу.

## 🚀 GitHub Pages арқылы сайтты тікелей іске қосу (Live Deployment)

Бұл жобаға **GitHub Pages** арқылы автоматты түрде жариялауға арналған `.github/workflows/deploy.yml` конфигурациясы толық орнатылған!

### Қадамдар:
1. GitHub-та жаңа репозиторий ашыңыз (мысалы: `nearpod-alternative`).
2. Компьютеріңізде немесе осы жобада кодты GitHub-қа жіберіңіз:
   ```bash
   git init
   git add .
   git commit -m "feat: initial commit of nearpod interactive platform"
   git branch -M main
   git remote add origin https://github.com/<СІЗДІҢ_GITHUB_ЛОГИНІҢІЗ>/<РЕПОЗИТОРИЙ_АТАУЫ>.git
   git push -u origin main
   ```
3. GitHub репозиторийіңіздің баптауларына кіріңіз:
   - **Settings** $\to$ **Pages** бөліміне өтіңіз.
   - **Build and deployment** $\to$ **Source** бөлімінен **GitHub Actions** параметрін таңдаңыз.
4. Автоматты түрде GitHub Actions іске қосылып, 1-2 минутта сайтыңыз келесі сілтемеде дайын болады:
   `https://<СІЗДІҢ_GITHUB_ЛОГИНІҢІЗ>.github.io/<РЕПОЗИТОРИЙ_АТАУЫ>/`

## 💻 Жергілікті ортада іске қосу (Local Development)

```bash
# Тәуелділіктерді орнату
npm install

# Әзірлеу серверін қосу
npm run dev

# Өндірістік нұсқаны жинау
npm run build
```
